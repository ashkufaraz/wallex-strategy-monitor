# پیامک پشتیبان هشدارها

ارسال از REST رسمی کاوه‌نگار با POST و کدگذاری فرم انجام می‌شود:
https://kavenegar.com/rest.html

کلید در `config/sms.json` خارج از مسیر عمومی و در GitHub Actions Secret با نام `KAVENEGAR_API_KEY` نگه‌داری می‌شود. کلید در API عمومی، لاگ یا مخزن قرار نمی‌گیرد. فایل تنظیمات سرور با دسترسی وب مسدود است.

فقط هشدارهای جدیدِ متعلق به `ashkufaraz@gmail.com` به شماره تنظیم‌شده پیامک می‌شوند؛ هشدارهای سایر کاربران به این شماره ارسال نمی‌شوند. هشدار نهایی، هشدار صرفاً شروط ورود و لغو، متن متمایز دارند.

مهلت تأیید اعلان ۹۰ ثانیه است. مرورگر باید وارد حساب مالک شده باشد و اعلان واقعاً به مسیر نمایش برسد. ساختن شیء Notification تأیید محسوب نمی‌شود؛ رویداد onshow یا موفقیت showNotification تأیید می‌شود. بازبودن صفحه به‌تنهایی کافی نیست. کاربران مهمان و سایر حساب‌ها نمی‌توانند پیامک مالک را متوقف کنند. تأیید مرورگر به معنی خوانده‌شدن پیام یا تضمین نمایش توسط سیستم‌عامل نیست.

Cron باید هر دقیقه اجرا شود. پس از مهلت، در اولین اجرای Cron ارسال صورت می‌گیرد؛ بنابراین ارسال الزاماً در ثانیه ۹۰ نیست. Worker دائمی نیز صف را پردازش می‌کند. اجرای مرورگر برای ارسال پیامک لازم نیست. در هر نوبت حداکثر ۵ پیامک پردازش می‌شود؛ هشدارهای بیش از یک ساعت و هشدارهای پیش از فعال‌سازی ارسال نمی‌شوند تا پس از قطعی، پیامک قدیمی و انبوه ارسال نشود.

شناسه درخواست پیش از اتصال شبکه رزرو می‌شود. در timeout یا قطع ارتباط، ارسال خودکار تکرار نمی‌شود چون ممکن است پیامک اول پذیرفته شده باشد. خطا و شناسه پیامک پذیرفته‌شده در گزارش رویدادها ثبت می‌شود. پذیرش API به معنی تحویل نهایی به گوشی نیست؛ وضعیت نهایی با متد status کاوه‌نگار قابل پیگیری است. کد ۴۳۰ یعنی حساب کاوه‌نگار هنوز احراز هویت نشده است.

برای تست محلی: `php tools/test-sms.php` (هر بار یک درخواست واقعی و هزینه‌دار). دکمه «آزمایش پیامک» نیز برای مدیر واردشده کنار تنظیمات موجود است و هر پنج دقیقه یک درخواست می‌پذیرد. تست‌های `tests/sms-fallback.php` بدون شبکه و بدون هزینه اجرا می‌شوند.
