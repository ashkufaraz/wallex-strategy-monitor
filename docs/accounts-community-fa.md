# حساب‌های کاربری و بخش عمومی

دیدن استراتژی‌ها، هشدارهای جاری و آرشیوشده، جزئیات ارزیابی، راهنماها و نظرات نیاز به ورود ندارد. ثبت نظر نیز عمومی است؛ نام و متن نظر نمایش داده می‌شوند. محدودیت درخواست برای ثبت‌نام، ورود و نظر روی سرور اعمال می‌شود.

هر فرد می‌تواند با نام، ایمیل و رمز ثبت‌نام کند. رمزها به‌صورت هش نگهداری می‌شوند و پس از ورود، شناسهٔ نشست و توکن CSRF تغییر می‌کند. ایمیل اعضای دیگر در پاسخ عمومی API نمایش داده نمی‌شود.

ثبت استراتژی به ورود نیاز دارد. شناسهٔ استراتژی مالک مشخص دارد و فقط همان کاربر می‌تواند آن را ویرایش، متوقف، فعال یا حذف کند. مالکیت با ارسال `owner_id` از مرورگر قابل تغییر نیست. مالک هشدار هنگام ایجاد هشدار ثبت می‌شود؛ حذف استراتژی آن مالکیت را از بین نمی‌برد. عملیات آرشیو، بازگردانی و حذف هشدار نیز فقط برای همان مالک مجاز است. «حذف هشدارهای من» به هشدارهای دیگران دست نمی‌زند.

استراتژی‌های پیش از راه‌اندازی ورود، طبق درخواست صاحب سایت به حساب رزروشدهٔ `ashkufaraz@gmail.com` تعلق دارند. این حساب با ثبت‌نام عمومی قابل تصاحب نیست. حساب مدیر هم اجازهٔ تغییر استراتژی‌های دیگر کاربران را ندارد؛ تنظیم فاصلهٔ عمومی پایش، دیدن لاگ‌های سیستم و حذف نظر نامناسب در اختیار مدیر سایت است.

برای آماده‌سازی فعال‌سازی اولیهٔ مالک، `python tools/prepare-owner-access.py --configure-github` اجرا می‌شود. فایل خصوصی `~/.config/wallex-strategy-monitor/owner-activation.html` لینک یک‌بارمصرف را بیرون از ریشهٔ وب نگه می‌دارد؛ فایل وارد Git یا بستهٔ انتشار نمی‌شود. فقط هش توکن در متغیر GitHub به نام `OWNER_BOOTSTRAP_HASH` ثبت و در تنظیم محافظت‌شدهٔ هاست منتشر می‌شود. صاحب حساب لینک را باز می‌کند و رمز اولیهٔ خود را تعیین می‌کند. پس از فعال‌سازی، همان لینک دوباره قابل استفاده نیست.

این قابلیت ثبت‌نام را به ارسال ایمیل، بازیابی رمز با ایمیل یا تأیید صندوق ایمیل متصل نمی‌کند. لینک فعال‌سازی مالک خصوصی است و نباید در نظرات یا مخزن قرار گیرد.
